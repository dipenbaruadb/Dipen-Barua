## App Name
Taka Manager - Personal Finance BD

## Short Description
বাংলাদেশি ব্যবহারকারীদের জন্য অফলাইন-ফার্স্ট স্মার্ট পার্সোনাল ফাইন্যান্স ম্যানেজার।

## Full Description
Taka Manager helps you track daily expenses, income, loans, gifts, shopping plans, budgets, and savings goals in one secure app.

### Why Taka Manager?
- Bengali-first interface
- Works offline (syncs when internet returns)
- Smart dashboard with insights and warnings
- Budget and goal tracking
- Loan and due reminder notifications
- Secure PIN and biometric protection

### Features
- Expense/Income/Loan/Gift transaction logging
- Category-based budgeting
- Monthly financial summaries
- Cloud backup and restore
- CSV/PDF report export
